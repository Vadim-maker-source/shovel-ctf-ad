# CTF payload generator

Запускается на той же Ubuntu, где работают Shovel и Suricata. Читает Shovel API и создаёт артефакты alert’ов. Для HTTP-потоков сохраняет Python replay-заготовку из Shovel, включая захваченное тело POST, если Suricata его сохранила. Генератор не отправляет replay-запросы.

```bash
cd "$HOME/shovel/payload-generator"
chmod +x install.sh
./install.sh
./run.sh
```

По умолчанию программа опрашивает `http://127.0.0.1:8000/api/flow` и сохраняет результаты в `$HOME/shovel/generated/`. Для тела HTTP Shovel использует `/api/flow/<id>/replay-http`; если тело не было захвачено или поток не HTTP, полную заготовку получить нельзя. API списка ограничен 100 последними потоками, поэтому при высокой нагрузке события могут быть пропущены. Сгенерированный replay воспроизводит захваченный запрос и требует проверки; это не автоматическое обнаружение уязвимости.
